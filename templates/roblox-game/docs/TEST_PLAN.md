# Test plan — {{GAME_NAME}}

Adapt after design approval. Do not claim these tests ran merely because this file exists.

1. Source: Rojo mapping, formatting, type/lint, static unit tests, content manifest and clean artifacts.

3. Multiplayer when relevant: 2 and max intended players, contested actions, join/leave, remotes, streaming, persistent agreement.

5. UI devices: keyboard, touch, controller, safe areas, camera, chat focus and accessible settings.
6. Visual/art: source-owned Blender template parity, silhouettes, attachments, gameplay collision, licenses and mobile rendering.
7. Performance: measured frame, memory, network and entity counts with device/client/scene recorded.
8. Private QA: correct place, source parity, private visibility, saved/published version, rollback snapshot.
9. Owner test drive: creative and enjoyment feedback AFTER engineering release candidate is prepared.
