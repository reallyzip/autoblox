# AutoBlox — 30-day zero-budget launch calendar

This schedule is relative to the day the owner applies GitHub topics and chooses to post publicly. **No posts or DMs are sent automatically.** Focus on working demos and audience relevance; adjust if the product has unresolved setup blockers.

| Day | Primary action | Proof / success metric |
| --- | --- | --- |
| 1 | Apply GitHub topics, homepage and social preview; verify download and docs | Repository About and release assets visible |
| 2 | Ask 2–3 trusted Roblox developers to install independently | Exact setup failures recorded |
| 3 | Record 20–30 seconds of real onboarding and Studio output | Demonstration shows real agent/tool access |
| 4 | Publish an honest launch post and demo short | Qualified repo visits, release downloads |
| 5 | Share a helpful tutorial in a relevant Roblox community where allowed | Questions, feedback, issue reports |
| 6 | Make one 4–8 minute getting-started walkthrough | Install steps reproducible by a beginner |
| 7 | Publish first-week recap; repair highest-friction step | Number of independent setup successes |
| 8–10 | Build a small original playable Roblox feature with a fresh AutoBlox project | Source commit, actual Studio evidence |
| 11–12 | Create three short clips from that feature | Retention, saves, comments from builders |
| 13–14 | Outreach to 5 relevant small creators, individually | Useful replies, demo requests |
| 15–17 | Run independent Codex/Claude comparison if both accessible | Honest results including failures |
| 18–20 | Fix reproducible issues and improve first-run guide | Reduced setup failures |
| 21 | Ship changelog / preview patch if warranted | Verified fix, release notes |
| 22–24 | Invite community game examples and contributors | Reproducible projects, actionable PRs |
| 25–27 | Record real Blender → Studio asset workflow, if validated | Model source, Studio import evidence |
| 28–29 | Publish how-to articles and an FAQ from user questions | Helpful organic search entry points |
| 30 | Share transparent results and next roadmap | Installs, downloads, stars, issues, demos, active contributors |

## Weekly scorecard

Record once weekly (actual figures only): GitHub stars/forks, release asset download counts, referrer/visitor counts when available, number of independent installers, verified Roblox Studio MCP connections, verified Blender MCP connections, successfully built mini-games, issues resolved, external contributions, creator mentions and content engagement.

**Decision gate:** Increase promotion only after independent users can successfully set up the toolkit and one end-to-end small game example is reproducible. Do not buy stars/views/reviews or mass-post unsolicited promotions.
