# AutoBlox roadmap

The current release is a **preview**. Project improvements depend on reproducible issues and independently verified results, not claims that every AI platform can autonomously ship a game.

## v0.3 preview — Public documentation and packaging

- Public-friendly GitHub README, install walkthrough, agent-specific copy/paste prompts, project examples and contribution guidance.
- Reproducible master-skill and full-toolkit ZIPs with SHA-256 sums.
- GitHub Actions package checks, release packaging and local consent-gated publishing helper.
- Original single master skill and 41 playbooks, neutral game template, first-run Studio/Blender MCP wizard.

## Next milestones

- Run real first-time setup tests on Windows and macOS for Codex and Claude Code.
- Confirm live Roblox Studio and Blender MCP calls for each supported client and report version-specific differences.
- Produce one small original game end-to-end using only AutoBlox instructions and public evidence.
- Expand adversarial agent testing for misleading pass claims, unnecessary tools, data-loss risk and blocked integrations.
- Review newcomer UX from community feedback; add only proven improvements.
- Consider more platform adapters and genre templates as contributor tests arrive.

No ETA or guaranteed compatibility certification is implied by this roadmap.
