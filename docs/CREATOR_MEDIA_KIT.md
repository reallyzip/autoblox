## Approved short descriptions

**One line:** AutoBlox is an open-source AI-assisted Roblox game-development workflow for Codex, Claude Code and other coding agents.

**30 seconds:** AutoBlox helps Roblox creators turn game ideas into scoped development plans and testable code. Its local-first toolkit includes one master skill, 41 original Roblox-focused playbooks, cross-agent adapters, game templates, optional Blender/Roblox Studio MCP setup and evidence-based release checks. It is a *preview toolkit*, not a guaranteed one-prompt complete-game generator.

## Credible video angles

1. **I tried an AI agent workflow for Roblox game development.** Show installing the skill, design council, a small working feature and what the agent actually verified.
2. **Codex vs Claude Code — same Roblox brief.** Start from separate fresh directories and compare exact outcomes, limitations, tests and time.
3. **Can AI use Blender and Roblox Studio together?** Demonstrate actual authorized read-only MCP connection; then an opt-in asset operation if supported.
4. **Building my first Roblox game with free tools.** Show the game scope, reusable template, Luau code and a Studio test, not hypothetical game footage.

## Footage and attribution

- Show genuine results only. Clearly mark concept art, mockups, emulators and unverified output.
- Keep player identities, private place IDs, auth credentials and personal paths out of captures.
- Creators may independently review the software, highlight limitations and use repository screenshots/owned assets consistently with their licenses.
- No sponsorship, payment, endorsement, guaranteed feature, or positive review is implied.
- Link to the repo and release. Do not imply affiliation with Roblox, Blender, Anthropic or OpenAI.
