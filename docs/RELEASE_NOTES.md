# AutoBlox v0.3.0 Preview

First public-ready distribution of AutoBlox, the local-first cross-agent Roblox game-development toolkit.

## Included

- One master Agent Skill with 41 original Roblox-focused playbooks.
- Neutral new-game scaffold, design council, supervisor and release-verification gates.
- Cross-agent project instructions for Codex, Claude Code, Cursor, Gemini CLI and GitHub Copilot/VS Code.
- Consent-based first-run environment wizard for Roblox Studio, Blender and optional MCP integration.
- Professional public README, platform-specific copy/paste prompts, installation and troubleshooting guides.
- Reproducible ZIP builder, offline unit tests, public publishing helper and SHA-256 checksums.

## Validation and limitations

- Offline unit and package checks are run before creating release archives.
- Live agent-to-Studio and agent-to-Blender MCP verification has **not** been established for all supported AI platforms.
- A preview toolkit cannot guarantee generation of a complete, functional game on arbitrary user hardware.
- No public Roblox experience, paid service or third-party bridge is bundled.

Please report reproducible issues using the templates under the Issues tab. Contributions and tested platform improvements are welcome.
