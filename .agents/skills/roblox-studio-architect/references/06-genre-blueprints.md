# Genre adapters — choose mechanics, do not inherit another game's design

Each adapter must produce a playable hero loop and one independently testable quality risk. All genres need cross-device controls, Roblox policy review, server validation, performance and first-session UX.

**Co-op survival/horror:** information gathering -> risk -> resource/action -> team rescue or escape -> consequence. Focus on readable danger, original creature silhouettes and solo viability; test server-owned threat targeting and avoid abusive/gory designs.

**FPS / shooter:** responsive aim -> combat engagement -> meaningful feedback -> objective outcome -> round/progression. Client may predict cosmetic feedback but server adjudicates hit validation, ammo, damage, movement and scoring. Test latency, controller aim, anti-exploit, assets/IP.

**Simulator / tycoon:** earn -> spend -> visible upgrade -> new choices -> next cycle. Guard the economy and purchase receipts; avoid autoplay, deceptive pay pressure and endless numbers without play.

**Social / roleplay:** customize -> communicate -> shared activities -> stories -> return. Use Roblox-native chat, permissions, moderation and safety, and varied opt-in social activities; do not bypass age-gated communication restrictions.

**Obby/platformer:** learn verb -> obstacle -> recover/checkpoint -> mastery -> optional variation. Test physical jump envelopes, checkpoints and fairness on touch/controller; no impossible jumps caused by camera/latency.

**RPG / adventure:** explore -> encounter -> choice/combat -> earned change -> quest impact -> return. Start with one region, one combat loop and one reason to replay; test save migration and scope of content authoring.

**Racing / vehicle:** join -> handle vehicle -> compete/time trial -> finish -> improve. Decide authoritative timing, checkpoints and vehicle ownership; test desync and recovery from overturned/abandoned vehicles.

**Puzzle / casual party:** learn rule -> surprising situation -> solve together/compete -> short resolution -> replay variation. Favor readable instructions, quick starts, spectator fairness and clean round resets.

These are planning prompts, not game specifications. Original concepts and the user's final choices override them.
