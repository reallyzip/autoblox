# Milestone Planning — Roblox Studio Architect

Origin reviewed: Superpowers/writing-plans
Activate when: Converting an approved game design into executable work
Outcome: Build the smallest polished end-to-end vertical slice before scale.

## Original Roblox production method

1. Decompose the spec into gameplay core, network security, playable world, player feedback, progression, art, device QA and release gates.
2. For every task define dependencies, exact source ownership, measurable acceptance, test method, failure recovery and exit artifact.
3. Prioritize a complete playable loop with progression and repeated sessions before decorative breadth.
4. Group tasks so one programmer or agent can finish and verify without touching many unrelated systems.
5. Record rejected nice-to-have features and owner decision gates to prevent scope creep during autonomous execution.

## Evidence required

- Plan with task IDs, priorities, dependency graph, evidence slots and stop/resume checkpoints.
- Each task ends at a reproducible verification checkpoint.

## Guardrail

Do not measure plan completeness by number of features or confuse planning with doing.

Other skills are optional sources of inspiration; this playbook is original project guidance, not a vendored copy.
