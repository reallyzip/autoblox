# Playbook Discovery — Roblox Studio Architect

Origin reviewed: Superpowers/using-superpowers
Activate when: Starting a new task and deciding what process guidance to use
Outcome: Route based on task and risk without inflating context.

## Original Roblox production method

1. Read the master skill once and identify the current stage: meeting, design lock, implementation, debugging, art, review or release.
2. Load only relevant original practice references using the routing map; a new task domain may add one or two more.
3. Apply instructions in order: owner permissions and current repo rules, approved design, engine requirements, selected playbooks.
4. If an optional external skill or connector is absent, use this package and native tooling rather than repeated setup attempts.
5. Do not silently change skill settings, global agent hooks or unrelated project configuration.

## Evidence required

- Selection remains stable across adjacent subtasks and can be explained in one sentence when asked.

## Guardrail

Never replace game-specific approvals with a broad instruction such as full autonomy.

Other skills are optional sources of inspiration; this playbook is original project guidance, not a vendored copy.
