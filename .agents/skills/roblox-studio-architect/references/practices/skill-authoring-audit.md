# Skill Authoring Audit — Roblox Studio Architect

Origin reviewed: Superpowers/writing-skills
Activate when: Designing, modifying, packaging or validating the reusable skill system
Outcome: Keep each instruction module discoverable, testable and maintainable.

## Original Roblox production method

1. Identify the exact failure the new playbook should prevent, then capture a baseline scenario where generic advice is insufficient.
2. Write narrow trigger wording, practical steps, evidence expectations and anti-patterns in original language.
3. Test on unrelated Roblox genres and failure conditions; compare behavior with and without the new guidance where tools permit.
4. Check no duplicate names, circular routing, broken relative links, licensing/credit errors or excessive default context.
5. Separate quick guidance from deep references and scripts; do not require users to install irrelevant dependencies.

## Evidence required

- Pressure-scenario test results, static packaging validation and documented limitations.
- Manifest coverage updated for any new or retired playbook.

## Guardrail

Do not publish an untested skill as a guaranteed autonomous game builder.

Other skills are optional sources of inspiration; this playbook is original project guidance, not a vendored copy.
