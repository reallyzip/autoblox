# Game Ui Ux — Roblox Studio Architect

Origin reviewed: awesome-gamedev/game-ui-ux
Activate when: Screen hierarchy, onboarding, menu flow or accessibility decisions
Outcome: Make the next action obvious and every important screen navigable.

## Original Roblox production method

1. Map the first-session path from join through first success and next-round choice; define the job of each screen and remove duplicate decisions.
2. Build one coherent typographic and spatial system: information priority, contrast, state change, contextual controls and safe margins.
3. Design without relying on mouse hover or fixed desktop pixels. Plan gamepad focus, touch targets, text scaling and keyboard dismissal.
4. Use notifications sparingly: critical events interrupt, routine results queue, and player actions receive feedback where attention already is.
5. For new players introduce one essential mechanic at a time; leave advanced details accessible without blocking play.

## Evidence required

- Complete a no-instructions first-session walkthrough with the intended devices.
- Capture viewport evidence at phone portrait/landscape if supported, tablet, desktop and controller.

## Guardrail

Never require precision clicking to complete gameplay or hide essential state inside decorative widgets.

Other skills are optional sources of inspiration; this playbook is original project guidance, not a vendored copy.
