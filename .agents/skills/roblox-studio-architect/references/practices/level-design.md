# Level Design — Roblox Studio Architect

Origin reviewed: awesome-gamedev/level-design
Activate when: Maps, missions, traversal, encounters, pacing or exploration layout
Outcome: Make objectives traversable, readable, varied and appropriately paced.

## Original Roblox production method

1. Start with player movement dimensions, camera clearance and abilities. Translate those metrics into route widths, gaps and vertical access.
2. Block out the full critical path using simple geometry before visual detail. Add safe alternates when a moving door/elevator may fail.
3. Design a tension curve with breathing room, learning beats and a deliberate finale; avoid continuously maxed-out challenge.
4. Measure travel times to objectives, spawn-to-first-action and recovery routes rather than judging layout from overhead art.
5. Add landmarks, signage and environmental storytelling only after route accessibility and incident ownership are tested.

## Evidence required

- Trace every required mission path in solo and multiplayer, including obstruction and respawn.
- Record travel distances/times from authoritative navigation points for tuning.

## Guardrail

Never decorate over interaction envelopes or make required paths rely on random geometry that can soft-lock progress.

Other skills are optional sources of inspiration; this playbook is original project guidance, not a vendored copy.
