# Visual Quality Gate — Roblox Studio Architect

Origin reviewed: Impeccable referenced in Upkeep AGENTS.md; source not accessible
Activate when: Final visual review or stylization consistency tasks
Outcome: Make a coherent world feel authored rather than randomly assembled.

## Original Roblox production method

1. Select a small reference frame representing the game tone, values, shape language, palette and character-to-world scale.
2. Compare playable camera views across menu, first five minutes, representative action and results; inspect clutter, hierarchy and silhouette.
3. Correct visual inconsistencies in prioritized order: blocking/readability, asset proportions, material coherence, animation, lighting, then micro-polish.
4. Compare improvements to mobile-sized views and the actual in-game render instead of approving only large concept images.
5. Keep the art style original and avoid recreating competing Roblox experiences.

## Evidence required

- Before/after images or Studio observations with device viewport and actual asset source identity.
- No text clipping, critical icon confusion or decorative occlusion in core routes.

## Guardrail

Do not interpret generic visual design advice as permission to import unlicensed assets.

Other skills are optional sources of inspiration; this playbook is original project guidance, not a vendored copy.
