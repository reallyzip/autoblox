# Create Game Assets — Roblox Studio Architect

Origin reviewed: awesome-gamedev/create-game-assets
Activate when: Any concept art, meshes, textures, sound assets, props or character appearance
Outcome: Convert a coherent art direction into reusable, provenanced in-game assets.

## Original Roblox production method

1. Inventory existing assets and establish an art bible: silhouettes, materials, palette, camera, target devices and genre-specific visual priorities.
2. Choose a representative hero asset and review it in-game before scaling production. Concept images are references, not geometry or proof of integration.
3. Maintain an asset ledger including author, origin/license, editable source, export, target Roblox template, dimensions and expected draw cost.
4. Prefer Blender for meaningful custom 3D modeling; prefer Roblox primitives and native UI for simpler structures. Normalize pivots, attachments and units.
5. Create asset families with intentional modular reuse, then integrate through the chosen authoritative source pipeline.

## Evidence required

- Validate exports, material mapping, alignment, lighting, silhouette legibility and import ownership in actual Roblox Studio.
- Produce a contact sheet or viewport evidence plus the manifest for every completed asset family.

## Guardrail

Never copy unlicensed Toolbox/script content or equate a nice render with a functional game asset.

Other skills are optional sources of inspiration; this playbook is original project guidance, not a vendored copy.
