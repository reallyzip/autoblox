# Concise Final Report — Roblox Studio Architect

Origin reviewed: Caveman/caveman
Activate when: Writing final status, evidence or handoff summaries
Outcome: Tell an owner what changed, what passed, what remains and what to do next.

## Original Roblox production method

1. Start with actual status: complete, partial, blocked or not started, never a ceremonial claim.
2. Identify changed work, source revision, runtime/publication identity and the smallest relevant test results.
3. Preserve exact commands, filenames, flags, error text and negations even in short summaries.
4. Separate observed facts from plans and unverified assumptions. Give one concrete next action when necessary.
5. For irreversible actions, permissions and security concerns favor full sentences and explicit cautions.

## Evidence required

- An unfamiliar developer can resume using the report without re-interviewing the implementer.

## Guardrail

Never shorten technical payloads or let compactness hide missing verification.
