# Code of Conduct

AutoBlox aims to be a welcoming, practical place for people learning and building original Roblox games.

Be respectful. Critique ideas and code rather than people. Avoid harassment, discrimination, threats, doxxing, and hostile or sexually explicit conduct. Respect different experience levels and do not pressure others to share private repositories, credentials, or player data.

Maintainers may edit, hide, or close abusive discussions and refuse contributions that violate these expectations. Report concerns privately to a repository maintainer through GitHub's available contact mechanisms, or open a public issue only if it does not disclose sensitive information. We will review reports in good faith; response times are not guaranteed.
